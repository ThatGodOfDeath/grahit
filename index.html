Graph Controls
🖱️ Select mode — Click a node or edge to select it
✋ Drag node — Move a node around the canvas
➕ Add Node mode — Click empty space to create a node
⇧ Shift + Click empty space — Quickly create a node
🔗 Add Edge mode — Click one node, then another
⇧ Shift + Click another node — Create an edge from the selected node
🗑️ Delete mode — Click a node or edge to delete it
⌫ Delete / Backspace — Delete the selected node or edge
Esc Escape — Return to Select mode and clear selection
🖱️ Middle mouse + drag — Pan the canvas
🔍 Mouse wheel — Zoom in/out
F F — Fit graph to canvas
R R — Reset view without changing zoom
